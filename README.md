# Тестовий сайт для UTM-міток віджета

1. Вставте код віджета в місце `<!-- ВСТАВТЕ КОД ВІДЖЕТА ТУТ -->` у трьох файлах: index.html, services.html, plugin.html.
2. Створіть репозиторій на GitHub і завантажте всі файли в корінь.
3. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
4. Через 1–2 хвилини сайт буде на `https://<логін>.github.io/<репозиторій>/`.

Діагностична панель на кожній сторінці показує мітки в адресі, вміст localStorage і cookies (оновлюється кожні 3 секунди).
